SECTION 01

View Basics

What is a View?

In Laravel, a View is responsible for presenting the application's user interface (UI).

Views usually contain:

  • HTML
  • CSS
  • JavaScript
  • Blade template syntax
  • Data received from controllers/routes

Laravel follows the MVC (Model–View–Controller) architecture:

  1. User Request
  2. Route
  3. Controller
  4. Model
  5. View
  6. HTML Response

The View is mainly concerned with how information is displayed to the user.

Location of Views

Laravel stores views inside:

resources/views

For example:

resources/views/welcome.blade.php

The .blade.php extension means that the file uses Laravel's Blade templating engine.

Creating a Basic View

Create:

resources/views/home.blade.php

Code:

html
<!DOCTYPE html>
<html>
<head>
    <title>Home</title>
</head>
<body>
    <h1>Welcome to Laravel</h1>
    <p>This is the home page.</p>
</body>
</html>

The view can then be returned from a route or controller.

SECTION 02

Calling Views from Routes and Controllers

There are two common ways to call a view:

  1. From a Route
  2. From a Controller
A

Calling a View from a Route

In routes/web.php:

php
<?php

use Illuminate\Support\Facades\Route;

Route::get('/home', function () {
    return view('home');
});

Here:

php
view('home')

tells Laravel to load:

resources/views/home.blade.php

Important Rule — you don't need to write view('home.blade.php'). Instead, write view('home'). Laravel automatically looks for the Blade file.

B

Calling a View from a Controller

First create a controller:

bash
php artisan make:controller HomeController

This creates:

app/Http/Controllers/HomeController.php

Controller:

php
<?php

namespace App\Http\Controllers;

class HomeController extends Controller
{
    public function index()
    {
        return view('home');
    }
}

Then define the route:

php
<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\HomeController;

Route::get('/home', [HomeController::class, 'index']);

Now when the user visits:

/home

Laravel executes:

  1. HomeController
  2. index()
  3. home.blade.php

Route → Controller → View

  1. Browser
  2. GET /home
  3. HomeController@index
  4. view('home')
  5. resources/views/home.blade.php

This approach is generally preferred when the page contains application logic.

SECTION 03

Nested Views

A nested view means placing views inside subdirectories within resources/views.

For example:

resources/views/
│
├── home.blade.php
│
├── users/
│   ├── index.blade.php
│   └── profile.blade.php
│
└── products/
    ├── index.blade.php
    └── details.blade.php

To access a view inside a folder, use dot notation.

For example:

php
return view('users.index');

Laravel looks for:

resources/views/users/index.blade.php

Example

Create:

resources/views/admin/dashboard.blade.php

Code:

html
<!DOCTYPE html>
<html>
<head>
    <title>Admin Dashboard</title>
</head>
<body>
    <h1>Admin Dashboard</h1>
</body>
</html>

Route:

php
use Illuminate\Support\Facades\Route;

Route::get('/admin/dashboard', function () {
    return view('admin.dashboard');
});

View Naming

View fileLaravel view name
home.blade.phphome
users/index.blade.phpusers.index
users/profile.blade.phpusers.profile
admin/dashboard.blade.phpadmin.dashboard
SECTION 04

Passing Data to Views

Usually, a view needs data from a route, controller, or model.

Laravel provides several ways to pass data to a view.

1

Passing an Associative Array

Route:

php
use Illuminate\Support\Facades\Route;

Route::get('/student', function () {
    $student = 'Rahul';

    return view('student', [
        'student' => $student
    ]);
});

Create:

resources/views/student.blade.php

Then:

blade
<h1>Student Name: {{ $student }}</h1>

Output:

Student Name: Rahul
2

Using with()

php
Route::get('/student', function () {
    return view('student')
        ->with('student', 'Rahul');
});

In Blade:

blade
<h1>{{ $student }}</h1>
3

Passing Multiple Values

php
Route::get('/student', function () {
    $name = 'Rahul';
    $age = 21;
    $course = 'Laravel';

    return view('student', [
        'name' => $name,
        'age' => $age,
        'course' => $course
    ]);
});

Blade:

blade
<h1>Name: {{ $name }}</h1>
<p>Age: {{ $age }}</p>
<p>Course: {{ $course }}</p>
4

Using compact()

A common and convenient approach is:

php
Route::get('/student', function () {
    $name = 'Rahul';
    $age = 21;

    return view('student', compact('name', 'age'));
});

Blade:

blade
<h1>{{ $name }}</h1>
<p>{{ $age }}</p>

How compact() works

This:

php
compact('name', 'age')

is equivalent to:

php
[
    'name' => $name,
    'age' => $age
]

Passing Data from a Controller

Controller:

php
<?php

namespace App\Http\Controllers;

class StudentController extends Controller
{
    public function index()
    {
        $name = 'Rahul';
        $age = 21;
        $course = 'Laravel';

        return view('student', compact('name', 'age', 'course'));
    }
}

Route:

php
use App\Http\Controllers\StudentController;

Route::get('/student', [StudentController::class, 'index']);

View:

blade
<h1>Student Information</h1>

<p>Name: {{ $name }}</p>
<p>Age: {{ $age }}</p>
<p>Course: {{ $course }}</p>
SECTION 05

Introduction to Blade Templating Engine

What is Blade?

Blade is Laravel's built-in templating engine.

Blade allows you to write dynamic HTML using simple syntax.

Blade files normally use:

.blade.php

Example:

resources/views/home.blade.php

Blade provides:

  • Variables
  • Conditions
  • Loops
  • Layouts
  • Components
  • Includes
  • Authentication-related directives
  • CSRF protection directives
  • Blade comments

Blade Variable Syntax

The most basic Blade syntax is:

blade
{{ $name }}

Example:

blade
<h1>Hello, {{ $name }}</h1>

If:

php
$name = 'Rahul';

Output:

Hello, Rahul

Blade Escaping

Blade's:

blade
{{ $name }}

escapes HTML output, which helps protect against XSS attacks.

Raw output can be written as:

blade
{!! $html !!}

Example:

php
$html = '<strong>Hello</strong>';

Blade:

blade
{!! $html !!}

This renders the HTML as HTML rather than displaying the tags.

Be careful with raw output when the content comes from users or other untrusted sources.

SECTION 06

Blade Directives

Blade directives are special instructions beginning with @.

Examples:

blade
@if
@else
@elseif
@endif
@foreach
@endforeach
@for
@endfor
@while
@endwhile
@include
@extends
@section
@yield
@csrf
A

@if

Used for conditional statements.

blade
@if($age >= 18)
    <p>You are an adult.</p>
@endif
B

@if, @else

blade
@if($age >= 18)
    <p>You are eligible to vote.</p>
@else
    <p>You are not eligible to vote.</p>
@endif
C

@elseif

blade
@if($marks >= 80)
    <p>Grade A</p>
@elseif($marks >= 60)
    <p>Grade B</p>
@elseif($marks >= 40)
    <p>Grade C</p>
@else
    <p>Fail</p>
@endif
D

@foreach

Used to iterate over an array or collection.

Route:

php
Route::get('/students', function () {
    $students = ['Rahul', 'Priya', 'Amit'];

    return view('students', compact('students'));
});

Blade:

blade
<h1>Students</h1>

<ul>
    @foreach($students as $student)
        <li>{{ $student }}</li>
    @endforeach
</ul>

Output:

Students

• Rahul
• Priya
• Amit
E

@for

blade
@for($i = 1; $i <= 5; $i++)
    <p>Number: {{ $i }}</p>
@endfor

Output:

Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
F

@while

blade
@php
    $i = 1;
@endphp

@while($i <= 5)
    <p>{{ $i }}</p>

    @php
        $i++;
    @endphp
@endwhile
G

@forelse

@forelse is useful when displaying a list that may be empty.

blade
@forelse($students as $student)
    <p>{{ $student }}</p>
@empty
    <p>No students found.</p>
@endforelse

This is often cleaner than writing a separate @if to check whether a collection is empty.

H

@isset

Checks whether a variable exists and isn't null.

blade
@isset($name)
    <p>Name: {{ $name }}</p>
@endisset
I

@empty

blade
@empty($students)
    <p>No students available.</p>
@endempty
J

@csrf

Used inside forms to generate a CSRF token.

blade
<form method="POST" action="/students">
    @csrf

    <input type="text" name="name">

    <button type="submit">Submit</button>
</form>

For POST, PUT, PATCH, and DELETE forms, using @csrf is important.

K

@method

HTML forms traditionally support GET and POST. Laravel allows method spoofing for other HTTP methods.

Example:

blade
<form method="POST" action="/students/1">
    @csrf
    @method('PUT')

    <input type="text" name="name">

    <button type="submit">Update</button>
</form>

Laravel interprets this as a PUT request.

L

@php

You can execute PHP code inside Blade:

blade
@php
    $message = 'Welcome to Laravel';
@endphp

<h1>{{ $message }}</h1>

However, business logic should generally remain in controllers/services/models rather than putting large amounts of PHP inside Blade.

SECTION 07

Template Inheritance Using Layouts

One of Blade's most useful features is template inheritance.

Imagine your website has:

  • Header
  • Navigation
  • Footer

Without layouts, you might repeat the same HTML in every page.

Instead, create one master layout and allow individual pages to fill specific sections.

Layout Structure

A common structure:

resources/views/
│
├── layouts/
│   └── app.blade.php
│
├── home.blade.php
├── about.blade.php
└── contact.blade.php

Step 1: Create the Layout

Create:

resources/views/layouts/app.blade.php

Code:

blade
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>@yield('title')</title>
</head>

<body>

    <header>
        <h1>My Laravel Website</h1>
    </header>

    <nav>
        <a href="/">Home</a>
        <a href="/about">About</a>
    </nav>

    <main>
        @yield('content')
    </main>

    <footer>
        <p>&copy; 2026 My Laravel Website</p>
    </footer>

</body>
</html>

The important part is:

blade
@yield('content')

This creates a placeholder where child views can insert their content.

Step 2: Create a Child View

Create:

resources/views/home.blade.php

Code:

blade
@extends('layouts.app')

@section('title', 'Home')

@section('content')

    <h2>Welcome Home</h2>

    <p>This is the home page.</p>

@endsection

Explanation

blade
@extends('layouts.app')

means:

Use layouts/app.blade.php as the parent layout.

Then:

blade
@section('title', 'Home')

fills:

blade
@yield('title')

with:

Home

And:

blade
@section('content')
    ...
@endsection

fills:

blade
@yield('content')

with the page's content.

SECTION 08

Multiple Sections in a Layout

A layout can contain multiple @yield() directives.

Example:

blade
<title>@yield('title', 'My Website')</title>

<header>
    @yield('header')
</header>

<main>
    @yield('content')
</main>

Child view:

blade
@extends('layouts.app')

@section('title', 'About Us')

@section('header')
    <h1>About Us</h1>
@endsection

@section('content')
    <p>Welcome to the About page.</p>
@endsection
SECTION 09

Including Views

Blade allows you to reuse a small view inside another view using:

blade
@include()

This is useful for reusable pieces such as:

  • Navbar
  • Footer
  • Alerts
  • Sidebar
  • Forms
  • Cards

Example Folder Structure

resources/views/
│
├── layouts/
│   └── app.blade.php
│
├── partials/
│   ├── navbar.blade.php
│   └── footer.blade.php
│
└── home.blade.php

Navbar

Create:

resources/views/partials/navbar.blade.php
blade
<nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
    <a href="/contact">Contact</a>
</nav>

Then include it:

blade
@include('partials.navbar')

Laravel looks for:

resources/views/partials/navbar.blade.php
SECTION 10

Including a View with Data

You can pass data to an included view.

Example:

blade
@include('partials.message', [
    'message' => 'Welcome to Laravel'
])

Then:

resources/views/partials/message.blade.php

contains:

blade
<div>
    <p>{{ $message }}</p>
</div>

Output:

Welcome to Laravel

Complete Example — Combining Everything

Let's create a small Laravel application using:

  • Routes
  • Controller
  • Nested views
  • Passing data
  • Blade
  • Directives
  • Layout inheritance
  • Includes

Project Structure

resources/views/
│
├── layouts/
│   └── app.blade.php
│
├── partials/
│   └── navbar.blade.php
│
└── students/

routes/web.php

php

use Illuminate\Support\Facades\Route;

    public function index()
    {
        $students = [
            'Rahul',
            'Priya',
            'Amit',
            'Neha'
        ];

        return view('students.index', compact('students'));
    }
}

resources/views/layouts/app.blade.php

blade
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>@yield('title')</title>
</head>

<body>

    @include('partials.navbar')

    <main>
        @yield('content')
    </main>

    <footer>
        <p>&copy; 2026 Laravel Application</p>
    </footer>

</body>
</html>

resources/views/partials/navbar.blade.php

blade
<nav>
    <a href="/students">Students</a>
</nav>

resources/views/students/index.blade.php

blade
@extends('layouts.app')

@section('title', 'Students')

@section('content')

    <h1>Student List</h1>

    @if(count($students) > 0)

        <ul>
            @foreach($students as $student)
                <li>{{ $student }}</li>
            @endforeach
        </ul>

    @else

        <p>No students found.</p>

    @endif

@endsection

Request Flow

When the user visits:

/students

the flow is:

  1. Browser
  2. Route
  3. StudentController@index
  4. $students array
  5. view('students.index', compact('students'))
  6. students/index.blade.php
  7. @extends('layouts.app')
  8. layouts/app.blade.php
  9. @include('partials.navbar')
  10. Final HTML response

SECTION 13

Common Errors and Their Solutions

ERROR 1View Not Found

You write:

php
return view('student');

but your file is:

resources/views/students.blade.php

This is a mismatch.

Either rename the file:

student.blade.php

or use:

php
return view('students');

ERROR 2Nested View Name Incorrect

File:

resources/views/admin/dashboard.blade.php

Correct:

php
return view('admin.dashboard');

Use dot notation for nested Blade views.

ERROR 3Undefined Variable

If your view contains:

blade
<h1>{{ $name }}</h1>

you must pass $name to the view:

php
return view('student', [
    'name' => 'Rahul'
]);

Otherwise Laravel will report an undefined variable.

ERROR 4Incorrect @extends

If your layout is:

resources/views/layouts/app.blade.php

use:

blade
@extends('layouts.app')

not:

blade
@extends('app')

ERROR 5Missing @end...

Incorrect:

blade
@if($age >= 18)
    <p>Adult</p>

Correct:

blade
@if($age >= 18)
    <p>Adult</p>
@endif

Similarly:

blade
@foreach($students as $student)
    <p>{{ $student }}</p>
@endforeach

ERROR 6Forgetting @csrf

For a POST form:

blade
<form method="POST" action="/students">
    @csrf

    <input type="text" name="name">

    <button type="submit">Save</button>
</form>

Don't omit the CSRF directive for Laravel POST forms.

class StudentController extends Controller
{

Route::put('/students/{id}', [StudentController::class, 'update']);

Laravel reads @method('PUT') and routes the submitted form to the update() method, even though HTML forms only support GET and POST natively.
