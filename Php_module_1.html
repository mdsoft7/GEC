PHP Basics

Introduction to PHP

Definition

PHP (recursively short for PHP: Hypertext Preprocessor) is an open-source, server-side scripting language purpose-built for the web. "Server-side" means the code runs on the web server, not in the visitor's browser: PHP reads your script, executes the logic, pulls in any data it needs, and hands the browser only the finished HTML — the source code itself is never exposed. It was created in 1994 by Rasmus Lerdorf and has since grown into one of the most widely deployed web languages, powering everything from small college portals to platforms like WordPress and Facebook's early architecture.

request → server → response
Browser
PHP + Server
HTML page
Why it matters: PHP powers a huge share of the web because it embeds directly inside HTML, has a gentle learning curve for beginners, and has first-class support on almost every hosting provider without extra setup.
Use case

Generating a personalised page — e.g. showing "Welcome back, Priya" by pulling a logged-in user's name from a database and printing it into the HTML before the page ever reaches the browser.

Tools & Software Requirements

Definition

Running PHP locally requires three cooperating pieces of software: a web server (commonly Apache or Nginx) that listens for browser requests, the PHP interpreter itself that executes your .php files, and usually a database engine (typically MySQL or MariaDB) for storing data. Rather than installing and configuring all three separately, most beginners use a bundled "stack" installer that wires them together automatically. A good code editor with PHP-aware autocomplete and error-checking rounds out the toolkit and saves hours of debugging.

PHP Syntax

Definition

A PHP script is marked off from surrounding HTML using the opening tag <?php and, optionally, a closing tag ?>. Everything between these tags is interpreted as PHP; everything outside them is sent straight through as plain HTML. Every individual instruction, called a statement, must end with a semicolon ; so the interpreter knows where one instruction stops and the next begins. Because PHP can be dropped into an HTML file at any point, a single file can freely alternate between static markup and dynamic logic.

hello.php
<?php
echo "Hello, students!";
?>

Mixing PHP with HTML — this is the pattern you'll use most while templating pages:

greeting.php
<h1>
  <?php echo "Welcome, " . $studentName; ?>
</h1>
Use case

A single .php file can serve a full HTML page where only a few words (a name, a price, a date) change per request, instead of maintaining a separate static file per visitor.

Comments in PHP

Definition

A comment is a piece of text in your source file that the PHP interpreter deliberately skips over — it produces no output and has no effect on the program. Comments exist purely for human readers: they explain intent, flag tricky logic, or temporarily disable a line of code without deleting it. PHP supports three comment styles, borrowed from C, C++ and shell scripting respectively, and all three can be mixed freely in the same file.

comments.php
<?php
// single-line comment
# also a single-line comment (shell-style)

/*
  multi-line comment —
  good for explaining a whole block
*/
echo "Comments don't print anything";
Try it

Explain why code does something in comments, not what it does — the code itself already shows the "what", so a good comment adds information the code alone can't.

Variables & Constants

Definition

A variable is a named container for a value that can change while the script runs; in PHP every variable name starts with a dollar sign $ and needs no upfront type declaration — PHP figures the type out from the value you assign. A constant, created with define() or the const keyword, is the opposite: once set, its value is locked for the rest of the script and any attempt to change it is ignored or triggers an error. Constants don't use the $ prefix, and by convention are written in UPPER_SNAKE_CASE so they stand out from ordinary variables at a glance.

assignment
"Ravi"
$studentName
ready to reuse
variables.php
<?php
$studentName = "Ravi";      // variable
$age         = 21;
$gpa         = 8.7;

define("COLLEGE_NAME", "GEC Gandhi Institute of Technology");
const MAX_MARKS = 100;   // constant, class/global scope

echo $studentName . " studies at " . COLLEGE_NAME;
Naming rules: variable names must start with a letter or underscore, are case-sensitive ($Age ≠ $age), and cannot contain spaces.
Use case

Use a constant for values that must never be edited by mistake — an API key, a tax rate, or a fixed maximum-marks value that every part of the program should agree on.

Data Types

Definition

A data type describes the kind of value a variable holds and, in turn, what you're allowed to do with it — you can add two numbers but not two arrays. PHP is a loosely (dynamically) typed language: you never declare a type up front, the interpreter infers it from the value assigned, and the very same variable can hold a string at one moment and an integer the next. This flexibility is convenient for quick scripts, but it also means it's worth checking a variable's type with functions like gettype() when its origin (like user input) isn't certain.

Operators

Definition

An operator is a symbol that performs an operation on one or more values, called operands. PHP groups them into families: arithmetic operators do maths, comparison operators test a relationship between two values and produce a boolean, logical operators combine boolean expressions, and assignment operators store or update a variable's value. Knowing the difference between == (loose equality, which converts types before comparing) and === (strict equality, which also requires matching types) is one of the most important early lessons in PHP, since it quietly causes a lot of beginner bugs.

Echo vs Print

Definition

echo and print are PHP's two built-in language constructs for sending text to the output (typically the browser). They behave almost identically for simple cases, which is why beginners often use them interchangeably, but they differ in two technical ways: echo accepts several comma-separated arguments in one call and returns no value, while print accepts exactly one argument and always returns the integer 1, which makes it usable inside a larger expression. Because echo skips the overhead of returning a value, it is marginally faster, though the difference is negligible in real applications.

echo_print.php
<?php
echo "Hello ", "World", "!";   // echo: multiple args, comma-separated
print "Hello World!";              // print: single arg only

$ok = print "this returns 1";   // $ok is now 1

Try it

In practice, reach for echo by default — it's the more common convention in PHP codebases and frameworks like Laravel.

What tag must every pure PHP statement be written inside?

Control Statements

if / if-else

Definition

The if statement is PHP's most basic decision-making tool: it evaluates a condition — any expression that resolves to true or false — and runs the code inside its curly braces only when that condition is true. Adding an else clause supplies a fallback block that runs whenever the condition turns out false, so exactly one of the two branches executes on any given run. Conditions are usually built from comparison operators (>=, ==, etc.) and can be combined with && or || for more complex logic.

if_else.php
<?php
$marks = 38;

if ($marks >= 40) {
    echo "Pass";
} else {
    echo "Fail — needs re-exam";
}
Use case

Deciding whether to show a "Pass" or "Fail" badge next to each student's result on a results dashboard.

if – else if – else

Definition

Real-world decisions often involve more than two outcomes, and that's what the elseif chain is for: PHP checks each condition strictly from top to bottom, runs the block belonging to the very first one that is true, and then skips every remaining elseif/else in the chain — even if a later condition would also have matched. Ordering therefore matters: put the most specific or highest-priority condition first, since it "wins" over broader conditions written below it.

first true branch wins
$marks >= 75 ?
"A" grade
check next condition
grade.php
<?php
$marks = 76;

if ($marks >= 90) {
    $grade = "A+";
} elseif ($marks >= 75) {
    $grade = "A";
} elseif ($marks >= 60) {
    $grade = "B";
} else {
    $grade = "C";
}
echo "Grade: " . $grade;   // Grade: A

switch statement

Definition

A switch statement compares a single value against a list of possible fixed cases and jumps straight to the matching one, making it a tidier alternative to a long elseif chain when you're testing one variable repeatedly. Each case must end with a break statement, or execution "falls through" and keeps running the code in the next case as well — a common source of beginner bugs. An optional default case catches any value that didn't match anything above it.

switch.php
<?php
$day = "Wed";

switch ($day) {
    case "Mon":
        echo "PHP Basics class";
        break;
    case "Wed":
        echo "Arrays & Strings lab";
        break;
    default:
        echo "No class scheduled";
}
// Output: Arrays & Strings lab
Try it

Remove the break; after the "Wed" case and re-run — notice it now also prints the default message. That's "fall-through".

Practice Questions — Control Statements

In an if–elseif–else chain, what happens once one condition matches?
ANSWERPHP runs that block's code and then skips every remaining elseif/else in the chain — only the first matching branch ever executes, even if a later condition would also be true.
What is "fall-through" in a switch statement, and how do you prevent it?
ANSWERFall-through happens when a case is missing its break, so execution keeps running into the next case's code instead of stopping. Adding a break; at the end of each case prevents it.
Rewrite this as an if-else: switch($x){case 1: echo "one"; break; default: echo "other";}
ANSWERif ($x == 1) { echo "one"; } else { echo "other"; } — a two-branch switch is functionally identical to a simple if-else.

Loops

for loop

Definition

A for loop repeats a block of code a predetermined number of times, packing three parts into a single header: an initializer that runs once before looping starts, a condition checked before every pass that stops the loop once it's false, and an increment/decrement that updates the counter after every pass. This makes for the natural choice whenever you already know — or can calculate — exactly how many times you need to repeat something.

repeat while condition holds
for
$i++
for_loop.php
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "Roll No. $i<br>";
}
// prints Roll No. 1 through Roll No. 5
Use case

Printing a numbered attendance list, or generating table rows 1 through N of a fixed size.

while loop

Definition

A while loop checks its condition before every single pass through the block, and keeps repeating for as long as that condition stays true. Unlike for, it doesn't require a built-in counter — it's the right tool when the number of repetitions isn't known ahead of time and instead depends on some changing state, such as remaining stock, a user's input, or data still left to read from a file.

while_loop.php
<?php
$stock = 3;

while ($stock > 0) {
    echo "Seat booked, remaining: $stock<br>";
    $stock--;
}

do…while loop

Definition

A do…while loop is the mirror image of while: it runs the block of code first, and only checks the condition afterwards to decide whether to loop again. That ordering guarantees the body executes at least once, no matter what the condition evaluates to — a subtle but important difference from a plain while loop, which might never run its body at all if the condition starts out false.

do_while.php
<?php
$attempt = 1;

do {
    echo "Attempt #$attempt<br>";
    $attempt++;
} while ($attempt <= 3);
Rule of thumb: reach for do…while for things like a login-retry prompt, where the first attempt must happen before you can even check the condition.

foreach loop

Definition

The foreach loop is purpose-built for arrays: it walks through every element in turn, automatically handing each one to a variable of your choosing, so you never have to manage an index counter by hand. It comes in two flavours — a simple as $value form for reading just the values, and a as $key => $value form that also gives you each element's key, which is essential when looping through an associative array.

visiting every element
Ravi
Priya
Aman
Next
foreach.php
<?php
$students = ["Ravi", "Priya", "Aman"];

foreach ($students as $name) {
    echo $name . "<br>";
}

// with key => value, e.g. for an associative array
$marks = ["Ravi" => 88, "Priya" => 92];
foreach ($marks as $name => $score) {
    echo "$name scored $score<br>";
}

break & continue

Definition

break and continue both alter a loop's normal flow, but in different ways. break exits the loop immediately and completely — execution jumps straight to the first line after the loop, and no further iterations happen at all. continue is gentler: it skips only the remaining code in the current pass and jumps straight back to the loop's condition check, so the loop keeps going with its next iteration.

break_continue.php
<?php
for ($i = 1; $i <= 10; $i++) {
    if ($i == 6) {
        break;              // stop the loop completely at 6
    }
    if ($i % 2 == 0) {
        continue;           // skip even numbers, keep looping
    }
    echo $i . " ";
}
// Output: 1 3 5

Practice Questions — Loops

When would you choose a do…while loop over a plain while loop?
ANSWERWhen the loop body must run at least once no matter what — e.g. showing a login prompt before you can even check whether the credentials were correct. while might skip the body entirely if the condition starts false; do…while never does.
What does foreach ($marks as $name => $score) give you that a plain foreach ($marks as $score) does not?
ANSWERThe $name => $score form also exposes each element's key (useful for associative arrays), while the plain form only gives you the value and discards the key.
What does this print? for($i=1;$i<=5;$i++){ if($i==3) continue; echo $i; }
ANSWERIt prints 1245 — continue skips only the iteration where $i equals 3, printing nothing that round, then the loop carries on normally.

Functions

Defining & Calling Functions

Definition

A function is a named, self-contained block of code that performs a specific task and can be executed — "called" — as many times as needed from anywhere in the script. You define it once using the function keyword followed by a name and a pair of parentheses, and you call it later simply by writing that name followed by parentheses. Functions are the primary way PHP programmers avoid repeating themselves: write the logic once, reuse it everywhere.

input → logic → output
input
function()
output
functions.php
<?php
function greetStudent() {
    echo "Welcome to the PHP lab!";
}

greetStudent();   // call it — prints the greeting
greetStudent();   // call it again, as many times as needed
Use case

Wrap any logic you'll repeat — validating an email, formatting a price, calculating a grade — into a function instead of copy-pasting the same code in multiple places.

Parameters & Return Values

Definition

Parameters are named placeholders listed inside a function's parentheses that let you feed outside data into the function each time it's called; the actual values you supply at call-time are called arguments. The return keyword sends a value back out of the function to wherever it was called from, which lets you capture that result in a variable, print it, or feed it straight into another expression — without return, a function can still run code but has nothing to hand back.

params_return.php
<?php
function calculatePercentage($obtained, $total) {
    return ($obtained / $total) * 100;
}

$result = calculatePercentage(450, 500);
echo $result;   // 90

Default & Variable-Length Arguments

Definition

A default argument is a fallback value written into the function's own definition, which is used automatically whenever the caller leaves that parameter out — this makes some arguments effectively optional. A variadic parameter, written with three leading dots (...$name), lets a single function accept any number of arguments at all, from zero upward, by silently collecting them into a regular array inside the function body. The two features solve different problems: defaults make a fixed parameter optional, while variadics remove the fixed count entirely.

default_variadic.php
<?php
// default argument
function enroll($name, $course = "PHP Basics") {
    echo "$name enrolled in $course<br>";
}
enroll("Ravi");                 // uses the default course
enroll("Priya", "MERN Stack");  // overrides the default

// variable-length (variadic) arguments
function total(...$marks) {
    return array_sum($marks);
}
echo total(90, 85, 76, 88);   // 339 — any number of args works

Practice Questions — Functions

What is the difference between a parameter and an argument?
ANSWERA parameter is the named placeholder listed in the function's own definition (e.g. $total in function calc($total)). An argument is the actual value supplied when the function is called (e.g. calc(500) — 500 is the argument).
Write a function square($n) that returns a number squared.
ANSWERfunction square($n) { return $n * $n; } — call it with square(6) to get 36.
What happens if you call enroll("Ravi") when the function is defined as function enroll($name, $course = "PHP Basics")?
ANSWERPHP uses the default value for the missing argument, so it behaves as enroll("Ravi", "PHP Basics") and prints "Ravi enrolled in PHP Basics".

Variable Scope

Global, Local & Static Scope

Definition

Scope defines the region of a script where a particular variable can be seen and used. A local variable is declared inside a function and exists only for that function's own call — it is invisible outside, and even a same-named variable outside is treated as a completely separate one. A global variable is declared outside every function, at the top level of the script, but is not automatically available inside a function unless you explicitly pull it in with the global keyword. A static variable is declared inside a function using the static keyword, and — unlike an ordinary local variable, which resets every time the function is called — it keeps its value between calls, only being initialised the very first time.

local lives inside · global lives outside
global scope
local scope
local_global.php
<?php
$collegeName = "GEC Gandhi Institute of Technology";  // global

function showCollege() {
    $collegeName = "Local College";   // local — different variable!
    echo $collegeName;               // "Local College"
}
showCollege();
echo $collegeName;   // still "GEC Gandhi Institute of Technology"

function printGlobalCollege() {
    global $collegeName;      // pulls the outer variable in
    echo $collegeName;
}
printGlobalCollege();   // "GEC Gandhi Institute of Technology"
static_scope.php
<?php
function countVisits() {
    static $visits = 0;   // initialised only once, ever
    $visits++;
    echo "Visit number: $visits<br>";
}
countVisits();  // Visit number: 1
countVisits();  // Visit number: 2
countVisits();  // Visit number: 3 — value persisted!
Use case

Static variables are handy for a simple call counter, a cache flag, or tracking "has this run before?" inside one function without resorting to a global variable.

Practice Questions — Scope

A variable is declared inside a function. Can it be accessed outside that function? Why?
ANSWERNo — it is a local variable, so it exists only for the duration of that function call and is destroyed once the function finishes. Code outside the function has no way to see it.
Why does a static variable "remember" its value between calls, unlike a normal local variable?
ANSWERThe static keyword tells PHP to initialise the variable only once, the very first time the function runs, and then keep its value in memory between calls instead of resetting it every time the function starts.
What keyword lets a function read (not just create) a variable declared outside it?
ANSWERThe global keyword, used inside the function as global $variableName;, before using that variable in the function body.

Arrays

Anatomy of an Array

Definition

An array is a single variable capable of holding multiple values at once, with each individual value reachable through its own key — either an automatic numeric position or a name you chose yourself. Internally, PHP stores an array as an ordered list of key-value pairs, which is why iterating over one always visits elements in a predictable, consistent order. You can picture an array as a row of labelled boxes that all share a single variable name, where the label on each box is its key and the contents are its value.

$fruits
Apple0
Mango1
Banana2
anatomy.php
<?php
$fruits = ["Apple", "Mango", "Banana"];
//         key 0      key 1      key 2   ← keys are automatic here

echo $fruits[1];   // "Mango"

Indexed Arrays

Definition

An indexed array is the simplest and most common array form in PHP: its keys are automatically assigned as sequential integers starting at 0, and you never have to specify them yourself unless you want a custom starting point. Because position, not a label, identifies each element, indexed arrays are the natural choice whenever the order of items matters more than giving each one a meaningful name — a list of subjects, a queue of tasks, a set of scores in the order they were entered.

indexed_array.php
<?php
$subjects = ["PHP", "MERN", "DBMS"];

// loop with for (index-based)
for ($i = 0; $i < count($subjects); $i++) {
    echo ($i + 1) . ". " . $subjects[$i] . "<br>";
}

// loop with foreach (value-based)
foreach ($subjects as $subject) {
    echo $subject . "<br>";
}

Associative Arrays

Definition

An associative array replaces automatic numeric keys with custom keys that you choose — usually descriptive strings — so each value is retrieved by a meaningful label instead of a position. This turns the array into something like a small dictionary or record: instead of remembering "index 2 holds the marks", you write $student["marks"] and the intent is obvious from the code itself. Associative arrays are typically used to represent a single real-world entity that has several named attributes.

$student
Habibname
MERNcourse
91marks
assoc_array.php
<?php
$student = [
    "name"  => "MD Habib",
    "course" => "MERN Stack",
    "marks"  => 91
];

echo $student["name"];   // "MD Habib"

// loop with foreach ( key => value )
foreach ($student as $field => $value) {
    echo "$field: $value<br>";
}
Use case

Representing one record — a student, a product, a form submission — where every value has a meaningful name attached to it.

Array Functions

Definition

PHP ships dozens of built-in functions for inspecting, growing, shrinking, searching and reshaping arrays, so you rarely need to write this logic by hand. Broadly they fall into a few families: functions that add or remove elements from either end (array_push, array_pop, array_shift, array_unshift), functions that search or test membership (in_array, array_search), functions that reorder or reshape the whole array (sort, array_merge, array_reverse), and functions that extract just the keys or values. Practice Questions — Arrays

What is the key difference between an indexed array and an associative array?
ANSWERAn indexed array uses automatic sequential integer keys starting at 0, while an associative array uses custom keys — usually descriptive strings — that you choose yourself.
Given $marks = [72, 88, 65];, what does array_pop($marks) return, and what does $marks look like afterward?
ANSWERIt returns 65 (the last element) and removes it, leaving $marks as [72, 88].
How would you find out whether the value 88 exists anywhere in $marks?
ANSWERUse in_array(88, $marks) — it returns true or false. If you also need to know where it is, use array_search(88, $marks) instead, which returns the matching key.
What does array_merge([1,2], [3,4]) return?
ANSWER[1, 2, 3, 4] — the two arrays are combined into one, in order, with fresh sequential keys for indexed arrays.

Formatting Strings — Presentation vs. Storage

Definition

Formatting for presentation means reshaping text purely so a human reader finds it clearer or more attractive — capitalising each word of a name before displaying it, or reversing text for a stylised banner. Formatting for storage means cleaning text so it's consistent, predictable and safe before it is saved somewhere permanent, such as a database — trimming stray leading and trailing spaces, or lower-casing an email address so "Ravi@Mail.com " and "ravi@mail.com" are recognised as the very same account rather than two different ones. The two goals sometimes call for the same function used differently, so it helps to always ask which one you're solving for before writing the code.

presentation.php
<?php
$name = "md habib";
echo ucwords($name);   // "Md Habib" — nice for display
storage.php
<?php
$email = "  Ravi@Mail.com  ";
$clean = strtolower(trim($email));
echo $clean;   // "ravi@mail.com" — safe & consistent for the database

Joining & Splitting Strings

Definition

implode() takes an array and glues all of its elements together into a single string, placing your chosen separator between each pair of elements. explode() performs the exact opposite operation: it takes one string and breaks it apart into an array, cutting wherever a given separator character or substring appears. Used together, the pair lets you move data freely back and forth between "array form" (easy to loop over and manipulate) and "string form" (easy to store, print, or send in a URL).

join_split.php
<?php
$subjects = ["PHP", "MERN", "DBMS"];
$csv = implode(", ", $subjects);
echo $csv;   // "PHP, MERN, DBMS"

$back = explode(", ", $csv);
print_r($back);   // ["PHP","MERN","DBMS"]
Use case

implode() is perfect for turning a tags array into a comma-separated string to store; explode() is perfect for turning a submitted comma-separated form field back into an array.

Comparing Strings

Definition

The simplest way to compare two strings is with == or ===, which tell you only whether they are equal or not. When you need to know more — specifically, which of the two strings would come first alphabetically — reach for strcmp(), which returns a negative number, zero, or a positive number depending on how the strings order against each other, or strcasecmp() for the same comparison while ignoring letter case entirely. These comparison functions are especially useful when building your own custom sorting logic.

compare.php
<?php
var_dump("php" == "php");            // true
var_dump("php" === "PHP");           // false — case-sensitive

echo strcmp("apple", "banana");   // negative -> "apple" sorts before "banana"
echo strcasecmp("PHP", "php");  // 0 -> equal, ignoring case

Practice Questions — Strings

What does trim(" hello ") return, and why is this useful before saving user input?
ANSWERIt returns "hello", with the leading and trailing spaces stripped. Trimming input before saving prevents accidental duplicate-looking records caused by invisible extra whitespace.
What is the difference between ucfirst() and ucwords()?
ANSWERucfirst() capitalises only the very first letter of the whole string, while ucwords() capitalises the first letter of every word in the string.
How would you turn the string "php,mern,dbms" into an array of three subjects?
ANSWERUse explode(",", "php,mern,dbms"), which splits the string wherever a comma appears and returns ["php","mern","dbms"].
What does substr("Hello World", 6, 5) return?
ANSWER"World" — it starts extracting at index 6 (the "W") and takes 5 characters from there.

1. Which tag correctly opens a block of PHP code?

PHP code blocks always begin with <?php.

2. What will var_dump(5 === "5") print?

=== is strict — it compares type as well as value, and 5 (int) is not the same type as "5" (string).

3. Which loop is guaranteed to run its body at least once?

do…while checks its condition only after running the body once, so the body always executes at least one time.

4. Inside a switch, what happens if you forget a break;?

Without break, PHP keeps executing the code in the following case(s) too — this is called "fall-through".

5. What does a static variable inside a function do?

A static variable is initialised only once and then remembers its value across every subsequent call to that same function.

6. Which function adds a new element to the end of an array?

array_push() appends to the end; array_unshift() adds to the start; array_shift() removes from the start.

implode() joins array elements into one string, placing the given separator between each pair of elements.

8. Which associative-array syntax correctly reads the "marks" value?

Associative array values are read using square brackets with the key inside quotes: $student["marks"].
